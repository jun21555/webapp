### ふせチャレ（app07/phone-down）

- 「スマホを伏せてスタート」→ 画面を下にして置くと計測開始、持ち上げると終了（傾きセンサーを使用。iPhone では初回に「動作と方向」へのアクセスを許可）
- さわらなかった1秒ごとに 1pt × 倍率。倍率は10分ごとに +0.5、最大 ×5（80分〜）なので、長く離れるほど一気に伸びる
- 離れた時間に応じて 🌱ふたば（1分）〜 🐉森のぬし（6時間）まで12種類の生きものが「デトックスの森」にやってくる。図鑑・自己ベスト・1週間グラフ・目標連続達成日数つき
- 「さわらないモード」: センサーが使えない端末・PC 向け。画面にさわったら終了
- 計測中は画面を点けたままにします（Screen Wake Lock）。画面が消えたり別アプリを開いたりするとその時点で終了。対応していない場合は iPhone の自動ロックを「なし」に
- 記録は端末内（localStorage）にのみ保存

### マップレーサー（app06/map-racer）

- 「地図からコースを作る」で地図をタップして通過ポイントを3つ以上置くと、道路に沿ったルート（OSRM）で周回コースを自動作成。最後のポイントから自動でスタートに戻ります。場所検索・現在地・ポイントのドラッグ移動・直線モードあり
- コースの形は「周回」と「片道」から選択。片道はスタート→（通過ポイント）→ゴールの順に2つ以上置き、走る前に「往路（スタート→ゴール）」「復路（ゴール→スタート）」を選べます。ベストタイムは往路・復路で別々に記録
- 作ったコースは端末内（localStorage）に保存され、タイトル画面からいつでも走れます。「保存」だけ／「保存して走る」、名前の変更（✏️）・削除（🗑）に対応
- 最高速度：設定で「遅め（約105km/h）／普通（約140km/h）／速め（約185km/h）」を選択。ライバル車の速さも同じ割合で変わり、ベスト記録は速度ごとに別々に保存
- 高低差：実際の標高（Open-Meteo Elevation API／Copernicus DEM 約90m）をコースに沿って取得し、坂道と起伏のある地形・建物を再現。上り坂は遅く下り坂は速くなります。設定で「なし／実際／×2／×4」を選べます（強調するとジェットコースター風）。標高データはコースと一緒に保存・書き出しされます
- 信号機と交差点名：OpenStreetMap にある実在の信号機と交差点名（例：桜田門）を、コースが通る交差点に表示。日本式の横型信号（青→黄→赤に切り替わる。見た目だけ）・停止線・青い交差点名標識を設置し、近づくと画面上部にも交差点名を表示。ミニマップには信号の位置を緑の点で表示。設定でオン／オフ可
- OpenStreetMap に信号機が登録されていないコースでは、地図データから推定して表示（設定「見つからない時は地図から推定」）。信号機は幹線道路（国道・都道府県道クラス）とコースが交わる交差点に置き、建物・道路データも取れない時はルート検索（OSRM）の曲がり角を使用。名前のない交差点には、国土地理院の住所検索で調べた町名・丁目（例：霞が関二丁目）か、交わる道路の名前を表示。推定したものは画面上の交差点名に「地図から推定」と表示
- 交差点・信号機を自分で設定：エディタの「置くもの」を「🚥 交差点・信号」にしてコース上をタップすると、交差点名と信号機の有無を設定できます（コースに吸い付く。印をタップで変更・削除、ドラッグで移動）。自分で設定したものは OpenStreetMap や推定より優先。作成済みのコースもコース一覧の「⋯」→「コースを編集」で追加・変更でき、プリセットは「コピーして編集」
- 走り始めに、表示できた信号機・交差点名の数（表示できなかった時はその理由）をお知らせ。ポーズメニューでも確認できます
- 初回に読み込んだ建物・道路・公園・水辺のデータはコースごとに端末内（IndexedDB）へ保存され、2回目以降は通信なしですぐ表示されます。コース一覧に保存状況とサイズを表示。「⋯」メニューから最新データへの取り直し・保存データの削除・名前変更・コース削除ができます
- 「コースを書き出す」で自作コースを JSON ファイルにバックアップ（iPhone では共有シートから「ファイルに保存」など）。建物・道路データも含めるか選べます。「読み込む」で別の端末やブラウザに移せます
- 走るときにコース周辺の建物・道路・公園・水辺を OpenStreetMap（Overpass API）から読み込み、実際の街並みを3Dで再現（取得できない場合は自動生成の街並み）。オフラインで遊べる「テストサーキット」「テストスプリント（片道）」と、皇居一周・お台場のプリセットつき
- 操作は「タッチ」（◀▶ボタン）と「傾き」（スマホをハンドルのように回す。iPhone では「動作と方向」へのアクセスを許可）から選択。オートアクセル、傾きの感度・反転、走行中の中心合わせ（ポーズメニュー）に対応
- 「ドリフト」を押しながら曲がるとドリフト。長く続けるほど火花が 青→オレンジ→紫 に変わり、離すとミニターボ。ドリフト中にハンドルを逆に切ると角度が浅く、同じ向きに切ると深くなる
- 1／3／5周、ライバル車（なし／ふつう／つよい）、カメラ3種、ミニマップ、ラップタイム・自己ベスト記録（端末内に保存）
- PC：←→ ハンドル / ↑ アクセル / ↓ ブレーキ / Space ドリフト / C カメラ / Esc ポーズ
- 3D描画は three.js、地図は Leaflet（どちらも `lib/` に同梱）

### ゆで卵タイマー（app06/boiled-egg-timer）

- スライダー・±30秒ボタン・プリセット（5:00 とろとろ／6:30 とろとろ半熟／8:00 しっとり／10:00 固ゆで）で 3〜15分の時間をセット
- 時間に合わせて卵の断面イラストと状態名・説明（白身ぷるぷる → とろとろ → 半熟 → しっとり → 固ゆで → ゆですぎ）が変わる
- タイマー中は「いまの卵」が経過時間に合わせて少しずつ固まっていく様子を表示
- 「ゆで時間と卵の状態」早見表つき。行をタップするとその時間にセット
- 目安は「沸騰したお湯に冷蔵庫から出したMサイズの卵を入れた場合」。常温の卵は約1分短く、Lサイズは約30秒長めに
- ゆで上がると通知（🥚 ゆで上がり！）・アラーム音・バイブ（対応端末のみ）でお知らせ。通知の条件（iOS 16.4 以降・ホーム画面に追加して開く・アプリを完全に終了しない）はカップ麺タイマーと同じです

### カップ麺タイマー（app06/cup-noodle-timer）

- 「3分」「5分」ボタンをタップするだけでスタート。残り時間とできあがり時刻をリング表示
- できあがると通知（🍜 できあがり！）・アラーム音・バイブ（対応端末のみ）でお知らせ
- iPhone で通知を使うには iOS 16.4 以降で、Safari の共有ボタン →「ホーム画面に追加」から開き、「通知をオンにする」を許可してください（Safari のタブのままでは通知は使えません）
- サーバーを使わない仕組みのため、アプリを完全に閉じる（スワイプで終了する）と通知は届きません。タイマー中は画面を点けたまま／他のアプリに切り替える程度にしてください
- アラーム音は「無音＋アラーム」の音声を再生する方式で、画面ロック中でも時間ぴったりに鳴りやすくしています（消音スイッチがオンだと鳴りません）
- 途中でアプリを開き直しても残り時間は端末内に保存されているので続きから表示されます

### そら模様（app06/weather）

- 天気・気温・湿度・降水確率・気圧: [Open-Meteo](https://open-meteo.com/)（APIキー不要）
- PM2.5・黄砂（大気中ダスト濃度）: Open-Meteo Air Quality（CAMS 予測モデル）
- 花粉: 日本の花粉はキー不要の無料データが無いため、標準では季節の目安を表示。⚙︎ から Google Pollen API キーを入れると実測レベルを表示します（キーは端末内にのみ保存）。
- 地名: 国土地理院 逆ジオコーダー

### ゲレンデ積雪（app06/snow）

- 地域（北海道・東北・関東・長野・山梨・新潟・北陸・東海・西日本）のチップからスキー場を選択
- ☆ でお気に入り登録（3つまで、端末内に保存）。お気に入りは画面上部にカード表示
- スキー場をタップすると、山頂付近／山麓の推定値と7日間の降雪予報グラフ、近くのアメダス実測を表示
- 積雪・降雪の推定・予報: [Open-Meteo](https://open-meteo.com/)（気象モデル、APIキー不要）。スキー場の公式発表値とは異なることがあります
- 実測: 気象庁アメダス（40km 以内で積雪を観測している最寄り地点）。出典: 気象庁ホームページ
- スキー場の座標・標高は概略です。追加は `snow.html` の `RESORTS` に1行足すだけ

### EVOLVE（app06/evolve）

- 画面のどこでもドラッグで自機を移動、押している間オートショット（PC は矢印キー + Space、X で武器切替、P でポーズ）
- 敵を倒すと GENE（遺伝子）が溜まり、一定数ごとにゲームが「進化」する
  - 00 GENESIS: 横移動のみ・画面に弾1発の古典スタイル
  - 01 RAPID / 02 FREE MOVE / 03 SWARM / 04 CHROMA（色・遠近グリッド・BGM）
  - 05 SPREAD（3WAY）/ 06 LOCK-ON（押して捕捉 → 離してホーミングレーザー）/ 07 TITAN（ボス）/ 08 PULSE / 09 INFINITY 以降は無限
- 敵のドット絵は毎ウェーブ手続き生成。効果音・BGM は Web Audio で合成（進化に合わせてパートが増える）
- ハイスコアと最高到達 EVO は端末内に保存。オフラインでも遊べます
- iPhone の消音スイッチがオンだと音が出ません

### ネオンダッシュ（app06/neon-dash）

- 自動で右へ走るキューブを操作し、トゲやブロックを越えてゴールを目指すリズムアクション（1回ミスすると最初から）
- 操作: 画面のどこでもタップでジャンプ、押しっぱなしで着地ごとに連続ジャンプ（PC は Space / ↑ / W、Esc でポーズ）
- 黄色いパッド: 触れると大ジャンプ／黄色いリング: 空中でタップすると再ジャンプ
- ピンクのゲートで飛行モード（押している間上昇・離すと下降）、緑のゲートでキューブに戻る
- レベル: FIRST BEAT（★）/ NEON SKYLINE（★★）/ OVERDRIVE（★★★）。各レベルはボットで全区間クリアできることを確認済み
- 練習モード: 2秒ごとに自動でチェックポイントが置かれ、ミスしてもそこから再開
- BGM・効果音は Web Audio で合成（レベルごとに曲が違い、背景がビートに合わせて光る）。iPhone の消音スイッチがオンだと音が出ません
- ベスト記録・挑戦回数・キューブの色は端末内（localStorage）に保存。オフラインでも遊べます。横向きにすると先まで見渡せます

### 勇者の伝説（app06/brave-legend）

- 勇者＋仲間3人で旅をするRPG。4つの大陸を支配する四天王を倒すと、旅の扉で次の大陸へ。四天王を全滅させると魔王の大陸へ行ける
- 魔王を倒すと大地が裂けて「闇の世界」へ。2人の守護者（影の騎士・虚無の賢者）を倒すと真の魔王の城の結界が消え、真の魔王を倒すとエンディング
- 転職: サハル大陸の転職の神殿で、Lv15以上の仲間（勇者以外）が転職できる。Lv1に戻り能力は半分になるが、覚えた呪文は残る。賢者は「さとりのしょ」か遊び人Lv20で転職可能
- 仲間モンスター: 倒した魔物が起き上がって仲間になりたがることがある。町の「仲間の館」でパーティと入れかえ・あずけ・わかれる・新しい仲間の登録ができる
- カジノ: オアシスの町と闇の町。スロット／ハイ＆ロー（当たれば倍率ぶん増え、続けてダブルアップ可）。コインはゴールドに換金したり景品（はやてのつるぎ・さとりのしょ 等）と交換できる
- 操作: 十字キーで移動、A で足もとの町・ほこら・扉に入る、メニューで呪文・道具・装備・記録。戦闘は AUTO ボタンでおまかせ。PC は矢印キー・Enter・Esc
- ダンジョンは毎回同じ形の迷路（シード固定で生成）。宝箱と最奥のボスがある
- セーブは端末内（localStorage）。ホームボタンで戻るときと町に入ったときに自動で記録。BGM・効果音は Web Audio で合成

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000/app06/weather/weather.html
```

位置情報は https か localhost でのみ使えます。

## iPhone のホーム画面に追加

1. Safari でアプリのページを開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選ぶ
