### そら模様（app06/weather）

- 天気・気温・湿度・降水確率・気圧: [Open-Meteo](https://open-meteo.com/)（APIキー不要）
- PM2.5・黄砂（大気中ダスト濃度）: Open-Meteo Air Quality（CAMS 予測モデル）
- 花粉: 日本の花粉はキー不要の無料データが無いため、標準では季節の目安を表示。⚙︎ から Google Pollen API キーを入れると実測レベルを表示します（キーは端末内にのみ保存）。
- 地名: 国土地理院 逆ジオコーダー

### ゲレンデ積雪（app06/snow）

- 地域（北海道・東北・関東・長野・山梨・新潟・北陸・東海・西日本）のチップからスキー場を選択
- ☆ でお気に入り登録（3つまで、端末内に保存）。お気に入りは画面上部にカード表示
- スキー場をタップすると、山頂付近／山麓の推定値と7日間の降雪予報グラフ、近くのアメダス実測を表示
- 積雪・降雪の推定・予報: [Open-Meteo](https://open-meteo.com/)（気象モデル、APIキー不要）。スキー場の公式発表値とは異なることがあります
- 実測: 気象庁アメダス（40km 以内で積雪を観測している最寄り地点）。出典: 気象庁ホームページ
- スキー場の座標・標高は概略です。追加は `snow.html` の `RESORTS` に1行足すだけ

### EVOLVE（app06/evolve）

- 画面のどこでもドラッグで自機を移動、押している間オートショット（PC は矢印キー + Space、X で武器切替、P でポーズ）
- 敵を倒すと GENE（遺伝子）が溜まり、一定数ごとにゲームが「進化」する
  - 00 GENESIS: 横移動のみ・画面に弾1発の古典スタイル
  - 01 RAPID / 02 FREE MOVE / 03 SWARM / 04 CHROMA（色・遠近グリッド・BGM）
  - 05 SPREAD（3WAY）/ 06 LOCK-ON（押して捕捉 → 離してホーミングレーザー）/ 07 TITAN（ボス）/ 08 PULSE / 09 INFINITY 以降は無限
- 敵のドット絵は毎ウェーブ手続き生成。効果音・BGM は Web Audio で合成（進化に合わせてパートが増える）
- ハイスコアと最高到達 EVO は端末内に保存。オフラインでも遊べます
- iPhone の消音スイッチがオンだと音が出ません

### ネオンダッシュ（app06/neon-dash）

- 自動で右へ走るキューブを操作し、トゲやブロックを越えてゴールを目指すリズムアクション（1回ミスすると最初から）
- 操作: 画面のどこでもタップでジャンプ、押しっぱなしで着地ごとに連続ジャンプ（PC は Space / ↑ / W、Esc でポーズ）
- 黄色いパッド: 触れると大ジャンプ／黄色いリング: 空中でタップすると再ジャンプ
- ピンクのゲートで飛行モード（押している間上昇・離すと下降）、緑のゲートでキューブに戻る
- レベル: FIRST BEAT（★）/ NEON SKYLINE（★★）/ OVERDRIVE（★★★）。各レベルはボットで全区間クリアできることを確認済み
- 練習モード: 2秒ごとに自動でチェックポイントが置かれ、ミスしてもそこから再開
- BGM・効果音は Web Audio で合成（レベルごとに曲が違い、背景がビートに合わせて光る）。iPhone の消音スイッチがオンだと音が出ません
- ベスト記録・挑戦回数・キューブの色は端末内（localStorage）に保存。オフラインでも遊べます。横向きにすると先まで見渡せます

### 勇者の伝説（app06/brave-legend）

- 勇者＋仲間3人で旅をするRPG。4つの大陸を支配する四天王を倒すと、旅の扉で次の大陸へ。四天王を全滅させると魔王の大陸へ行ける
- 魔王を倒すと大地が裂けて「闇の世界」へ。2人の守護者（影の騎士・虚無の賢者）を倒すと真の魔王の城の結界が消え、真の魔王を倒すとエンディング
- 転職: サハル大陸の転職の神殿で、Lv15以上の仲間（勇者以外）が転職できる。Lv1に戻り能力は半分になるが、覚えた呪文は残る。賢者は「さとりのしょ」か遊び人Lv20で転職可能
- 仲間モンスター: 倒した魔物が起き上がって仲間になりたがることがある。町の「仲間の館」でパーティと入れかえ・あずけ・わかれる・新しい仲間の登録ができる
- カジノ: オアシスの町と闇の町。スロット／ハイ＆ロー（当たれば倍率ぶん増え、続けてダブルアップ可）。コインはゴールドに換金したり景品（はやてのつるぎ・さとりのしょ 等）と交換できる
- 操作: 十字キーで移動、A で足もとの町・ほこら・扉に入る、メニューで呪文・道具・装備・記録。戦闘は AUTO ボタンでおまかせ。PC は矢印キー・Enter・Esc
- ダンジョンは毎回同じ形の迷路（シード固定で生成）。宝箱と最奥のボスがある
- セーブは端末内（localStorage）。ホームボタンで戻るときと町に入ったときに自動で記録。BGM・効果音は Web Audio で合成

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000/app06/weather/weather.html
```

位置情報は https か localhost でのみ使えます。

## iPhone のホーム画面に追加

1. Safari でアプリのページを開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選ぶ
