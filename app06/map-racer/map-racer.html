あそびかた

  • 「ドリフト」を押しながら曲がるとドリフト。長く続けるほど火花の色が 青→オレンジ→紫 に変わり、離すとブースト！
  • ドリフト中にハンドルを逆に切ると角度が浅く、同じ向きに切ると深くなります。
  • 傾き操作は横向きでスマホをハンドルのように回します。iPhone では最初に「動作と方向」へのアクセスを許可してください。
  • PC：←→ ハンドル / ↑ アクセル / ↓ ブレーキ / Space ドリフト / C カメラ / Esc ポーズ
