花粉データの設定

日本の花粉（スギ・ヒノキ・イネ科など）は、無料・キー不要で取れるデータがありません。 Google Pollen API の API キーを入れると、現在地の花粉レベルを表示します。キーはこの端末の中だけに保存されます。
キーが無いときは、ヨーロッパなど対応地域ではモデル値を、それ以外では季節の目安を表示します。
